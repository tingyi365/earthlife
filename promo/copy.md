**內文：**

Play: https://earthlife.pages.dev

Fair warning up front: the game is in Traditional Chinese only, so for non-Chinese speakers the more interesting part is probably the repo.

It's a text-based life simulator with meme-card events: you get randomly reincarnated (talent, family, birthplace, even which era — dial-up BBS kid vs TikTok kid changes your event pool), advance year by year, make choices, die in creative ways, and collect deaths/achievements across runs. There's a daily challenge where everyone shares the same RNG seed, and a seed-battle mode to race a friend through an identical life.

The experiment behind it: after the initial prototype, every update (R1→R66) has been made by an AI agent with no human in the loop — it picks what to build, edits the code, runs a test gate that auto-plays 220 full lives headlessly, deploys if green, and writes design notes that become the next round's context. The whole game is a single 1.3MB HTML file, vanilla JS, no build step. MIT licensed.

## 6. Hacker News（Show HN）

**標題：**Show HN: EarthLife – a game that an AI agent has autonomously evolved for 66 rounds

**內文：**

Play (Traditional Chinese): https://earthlife.pages.dev
Repo: https://github.com/tingyi365/earthlife

EarthLife is a satirical text life-simulator, but the part I want to show HN is the release loop: after the initial prototype, I stopped writing features myself. An AI agent runs one iteration every 30 minutes:

1. Reads the current code and the structured design comments left by previous rounds (the code itself is the agent's long-term memory)
2. Decides what to build this round — new mechanic, balance pass, polish, or easter eggs
3. Edits the game directly
4. Test gate: two suites must pass — one extracts the game JS, stubs the DOM, and auto-plays 220 complete lives asserting zero runtime errors plus invariants (event reachability, save integrity, lifespan distribution); the other audits the state machine and legacy-save compatibility
5. Deploys to Cloudflare Pages and writes its changelog notes for the next round

66 rounds in, it grew from a 61-event prototype to 650+ events, 58 death types, 212 achievements, daily seeded challenges, and a deterministic seed-replay system (any life can be replayed from a 6-char seed code) — all in a single 1.3MB HTML file with no framework and no build step. Every round is a commit, so the full evolution is auditable.

Things that surprised me: the agent maintains its own determinism discipline — its code comments repeatedly enforce a "zero RNG consumption in UI code" rule so seed replays stay identical — and it treats the test gate as non-negotiable, refusing to ship rounds where the 220-life simulation found regressions.

The game is zh-TW only for now. Happy to answer questions about the loop design, the test gates, or what failed along the way.
