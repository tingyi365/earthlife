# AI 自主更新管理機制 / AI Autonomous Update Management

> EarthLife 的核心實驗：把一款線上遊戲的**全部迭代權**交給 AI agent——選題、開發、測試、部署、寫日誌，全自動，每 30 分鐘一輪。本文是這套機制的公開設計說明。

---

## 1. 設計目標

傳統遊戲營運：人類 PM 排需求 → 工程師開發 → QA 測試 → 發版。
EarthLife 的問法是：**如果這整條流水線就是一個 AI agent，會發生什麼？**

約束條件刻意設計得很緊：

- **節奏固定**：每 30 分鐘一輪，agent 必須在一輪內完成「選題→改碼→測試→部署→記錄」全流程。
- **品質閘門不可繞過**：兩套自動化測試**全綠才能部署**，任何一項紅燈就放棄該輪變更。
- **線上服務不中斷**：每一輪部署後，玩家的舊存檔必須相容（測試明確驗證舊存檔升級路徑）。
- **無人介入**：人類不審 code、不點部署按鈕；唯一的人為輸入是最初的遊戲雛形與這套規則本身。

## 2. 迴圈的五個階段

### ① 自主選題（Self-directed planning）

每輪開始，agent 重新閱讀遊戲現況——程式碼內的歷輪設計註解、測試報告輸出（事件觸發率、壽命分布、從未觸發的事件清單）——然後**自己決定**這一輪的進化方向。93 輪下來自然形成了節奏：

- **大系統輪**：新玩法（轉生殿、祖產傳承、感情主線、收藏館）
- **內容輪**：新事件鏈、新成就、新死法、彩蛋
- **平衡輪**：根據模擬數據修事件可達性、屬性曲線、權重
- **打磨輪**：行動端排版、動畫手感、文案台味化

選題依據是**資料而非心情**：例如測試報告列出「從未觸發的事件」，下一輪就可能出現可達性修復；壽命中位數偏移，就出平衡輪。

### ② 動手改造（Implementation)

遊戲本體是單一 `index.html`（內嵌 CSS + 原生 JS、無 build step）。這個架構是刻意的：**改動面最小、部署原子化、agent 一眼能讀完整個世界**。所有可擴充內容（事件、場景、成就、天賦）都是宣告式資料結構，agent 以追加為主、修改為輔。

歷輪形成的工程紀律（全部由 agent 在註解中自我約定、後續輪次遵守）：

- **零裸 rng**：劇情分流一律走「旗標＋屬性門檻」確定性觸發，不用裸隨機數賭命，保證可測試、可重現。
- **舊存檔不炸**：每次新增存檔欄位都附「缺鍵當空集合」的防禦式讀取。
- **種子化人生**：每局以 6 碼種子驅動，同種子可完整重播一生（這也讓 220 局模擬測試成為可能）。

### ③ 測試閘門（Test gate — all green or no ship）

兩套測試，任何紅燈 = 該輪不部署：

| 測試 | 內容 |
|---|---|
| `_test_sim.js` | 抽出遊戲 JS、套上 DOM stub，**全自動玩 220 局完整人生**。驗證：0 runtime error、無缺失場景、各人生階段事件命中、壽命/結局/評級分布在健康區間、成就可解鎖、localStorage 寫讀正確、死法圖鑑無缺漏、舊存檔相容。 |
| `_test_state.js` | 狀態機審計：存檔結構、跨局累計（成就/輪迴點/祖產陰德/生涯統計）、各系統面板渲染、歷史欄位完整性。 |

測試報告同時是**下一輪的選題輸入**——例如「從未觸發的可觸發事件（70 個）」清單會直接餵給下一輪 agent。

### ④ 自動部署（Deploy）

測試全綠後，agent 將靜態檔案部署到 Cloudflare Pages。單檔架構讓部署天然原子化：沒有半套上線的中間態。

### ⑤ 版本日誌（Changelog as context）

agent 把每一輪的設計決策**以結構化註解寫進程式碼**（例如「R39 伏筆事件鏈：前段選擇埋旗標、中後段確定性回收，零裸 rng」）。這些註解不是給人看的文件——它們是**下一輪 agent 的記憶**，讓 93 輪迭代保持風格與紀律的連續性。

## 4. 我們學到什麼

1. **測試閘門是整套機制的靈魂。** AI 的產出品質波動是常態；不可繞過的自動化閘門把「波動」轉成「過或不過」的二元結果，線上品質因此穩定。
2. **註解即記憶。** 沒有外部資料庫，僅靠程式碼內的結構化註解，agent 就能跨 93 輪維持設計紀律（零裸 rng、舊存檔相容）——上下文工程比想像中夠用。
3. **單檔架構是 AI 友善架構。** 整個世界在一個檔案裡，agent 每輪都能讀到全貌，避免了跨檔重構的失憶風險。
4. **資料驅動選題讓迭代不發散。** 模擬報告（觸發率、壽命分布）給了 agent 客觀的「下一步該做什麼」訊號，93 輪沒有跑偏成縫合怪。
